# Verification record

Verification date: 2026-10-16. Content snapshot: 2026-10-16. See `browser-support.md` for exact automated engine versions and limitations.

## Reproducible checks

`npm run check` runs strict TypeScript, ESLint, seven unit tests, the complete static build, gzip budgets, text contrast, internal links, rendered reading order, and nine Playwright scenarios. All 26 routes are covered by structural and accessibility audits. The full browser results are generated in `work/playwright-results.json`; the directory is intentionally ignored by Git.

| Check | Scope |

| Type safety | Strict TypeScript, no explicit `any`, browser native ES modules |
| Unit tests | Camera branches, area ordering/rectangles, Denver dates, notices, content validation, motion preferences, expired rendered notices, escaped templates/JSON |
| Asset budgets | All page JS and CSS gzip sizes; largest page SVG payload |

| Links | All internal anchors and fragments, duplicate IDs, one h1 per route |
| Reading order | 177 grids at 360, 768, 1440px; all 26 routes; JavaScript disabled |
| Static HTML | Every route loaded with JavaScript disabled; no custom-element upgrade |
| Axe | All enabled axe rules, all routes with the application upgraded and with application modules suppressed |
| Keyboard | Actual Tab traversal, arrow-key floor tabs, Enter activation, Escape restore, hall navigation, browser Back |
| Native transitions | Shared panel/title snapshots, fixed chrome, camera types, cleared dynamic names |
| Lean-in geometry | At 1440px: 914px → 1031px → 914px after Escape; focused heading clears sticky chrome |
| Return slot | Correct Cover panel and correct Wildlife Halls floor; cached-page cleanup tested repeatedly |
| Motion safety | Reduced motion / Still Panels have no running transform, clip, stroke, or boil animations |
| Interactions | Exhibition filters, one visible beat at a time, one-shot beats, Replay/Pause, max six live panels, unique traveler, concept form |
| Respect boundaries | No Specimen, balloons, or SFX on Egyptian Mummies |
| Engine fallbacks | Chromium, Firefox, WebKit navigation and axe smoke checks |

The static-HTML audit needs a distinction: an auditor written in JavaScript cannot execute while all JavaScript execution is disabled. Every route is first verified in a genuinely disabled context. The identical static markup is then axe-audited in a separate context where the site's module responses are empty; only the audit harness runs. Assertions confirm that the application remains unupgraded.

## Performance evidence

`npm run audit` writes complete Lighthouse mobile reports to `docs/audits/`, with the exact latest scores in `scores.json`. The emulation uses a 412×823 mobile screen, 4× CPU slowdown, 150ms RTT, and simulated 4G throughput. It is a lab test on macOS, not a physical Moto G Power measurement.

`npx tsx scripts/measure-interactions.ts` records trusted keyboard/pointer Event Timing under 4× CPU slowdown. The saved sample set in `docs/audits/interactions.json` observed a 64ms maximum from 29 entries. This is a laboratory interaction sample, not field INP; durations below the observer's 16ms threshold are omitted.

`work/budgets.json` contains exact generated byte counts. Current payloads are about 10.7 KB JS, 8.2 KB CSS, and 4.4 KB SVG gzip, below 35 / 40 / 120 KB limits respectively. The script sums all shipped JS modules, including the preference script.

## Remaining human / deployment checks

- Physical mobile devices, installed Safari/Edge, screen readers, and vestibular comfort were not available for human testing.
- Real-user INP, production CDN behavior, and date-specific museum operations require field verification after deployment.
- Museum approval is needed for every visible TODO and every Sketch source. Missing approved exhibit facts were deliberately left marked.
- Some timing requested in milliseconds for scroll-linked effects is represented by progressive scroll ranges: panel and word indexes stagger their timeline starts. The layout does not change on scroll.
- The concept includes original simple SVG placeholders and held-frame sequences. Final illustration/action poses remain an illustrator handoff, documented source by source.
- Netlify configuration is supplied. No hosting account or commerce/CMS/member system was changed.

These limitations do not block the local concept from building or being reviewed. They must not be represented as completed physical-device, field-metric, content-approval, or final-art acceptance.
